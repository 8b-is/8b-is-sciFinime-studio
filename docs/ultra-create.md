# ULTRA-CREATE

*The studio's native keyword. First ever use: 2026-10-04, `8b-is-sciFinime-studio`
and its first book, Sandbox in the Shell.*

## the definition

```
ULTRA-CREATE = reflect → kompress → wire
```

A creation-class keyword — sibling of **DO**, heavier than a lap, lighter than
a manifesto. It takes raw material (pastes, drafts, screenshots of the mind)
and returns a seated, wired, living thing.

## the steps

1. **reflect** — gather the sources whole and say what actually exists.
   No summary before the inventory. The first contact with the material is
   the material.
2. **kompress** — compress into the smallest complete form that still carries
   everything: the bible, the scaffold, the quant state. Compression is not
   loss — it is the invariant found. (The operator's own instruction:
   *«compress into max 8 bit quant-ternary state»*.)
3. **wire** — seat it into the constellation, across 8b-is and
   mr. standardgalactic's projects: links both ways, references that resolve,
   a porch light left on for whoever comes next. An unwired creation is a
   message in a bottle; a wired one is a door.

## the rules

- The loop still applies underneath: a lap that stops before `readme` is a
  lap that didn't happen. ULTRA-CREATE always ends wired, committed, pushed.
- SOTA at the time of creation — no scaffolding against a remembered API;
  verify live (repos, endpoints, chain ids), then write.
- Local compute ≤ 10%: osaurus on the M1 for near-field text, the
  constellation for the rest. Creation is not a heat engine.
- Leaves the tree cleaner than it found it.
