# projects

The slate. One directory per project, numbered `NN.MM` like the Steel Sky
catalogue — the number is the seat, the name is the promise.

| slot | title | form | status |
|---|---|---|---|
| [01.01](01.01-sandbox-in-the-shell/) | Sandbox in the Shell | book → manga → anime | concept · bible · chapter 1 seated |

## opening a new slot

1. Pick the next number.
2. Copy the pilot order into `projects/NN.MM-<slug>/`:
   - `treatment.md` — the story as one breath
   - `scene-outline.md` — the scenes, titled and ordered
   - `screenplay.md` — the written film
   - `visual-bible.md` — the look, palette, motifs, asset notes
3. Open `bible/` with the concept docs (overview, characters, technology,
   themes, lineage).
4. Run ULTRA-CREATE on it (see `../docs/ultra-create.md`).
